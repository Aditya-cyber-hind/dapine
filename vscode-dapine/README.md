\# Dapine VS Code Extension



Syntax highlighting and autocomplete for the Dapine data pipeline language.



\## Features



\- Syntax highlighting for .dap files

\- Autocomplete snippets for all Dapine commands

\- Bracket matching and auto-closing

\- Comment support (// and /\* \*/)



\## Install



Copy this folder to `%USERPROFILE%\\.vscode\\extensions\\dapine`



\## Usage



Open any `.dap` file in VS Code. Syntax highlighting activates automatically.

Type a command prefix and press Tab to autocomplete.
